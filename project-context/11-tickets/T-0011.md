  Spec:
    - The module docstring opens with the Gate 0 frame (later tickets quote it; don't restate it elsewhere):
      - Decision: which setpoint proposal(s) the operator sees for a confirmed defect;
      - Unit: one confirmed defect box (224 px crop + defect class) at confirmation time;
      - Target: the induced cause of the box's trial (09 §Data label rule);
      - Metric: LOGO mean top-1 (NFR-005). Error cost: a wrong actionable cause proposes a wrong-direction change
        (bounded by the gate), so per-class recall on actionable causes is the main diagnostic;
      - Baseline: the floor, i.e. the majority cause per defect class (T-0010).
    - `build_model(n_causes, n_defects)`:
      - torchvision resnet18(weights=IMAGENET1K_V1) with fc removed;
      - concat the 512-d features with the defect one-hot;
      - Linear → n_causes.
    - `CauseModel.predict(crop_bgr, defect)`:
      - BGR → RGB, resize to 224, ImageNet normalisation;
      - softmax → CauseEstimate.
      - Its signature accepts ONLY (crop, defect); the test asserts this (leakage guard).
    - `train_one_epoch(model, loader, opt, class_weights)` lives here too, reused by T-0012.
