# ADR-0006 — Critical-class response is configurable; default matches the deck (M112)

STATUS:      accepted (clog default pending Dr. Meti, branch B3)
DATE:        2026-10-03
REVERSIBLE:  cheap

## Context
The deck sends M112 for clog, layer shift and spaghetti. M112 halts Marlin and needs a reset, so the print can't be recovered. A clog may be recoverable after a pause.

## Decision
`critical_action` per class in config: `estop` (M112) or `pause` (OctoPrint job pause, followed by a proposal card). Default `estop` for all three classes. An explanation is still generated and logged *after* the stop, never before it.

## Consequences
Behaviour stays identical to the REU loop unless the guide approves the change.
