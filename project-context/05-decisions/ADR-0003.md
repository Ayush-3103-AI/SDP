# ADR-0003 — Split-conformal (LAC) cause sets at risk α

STATUS:      accepted
DATE:        2026-10-03
REVERSIBLE:  cheap

## Context
"Range of solutions" plus the deck's "calibrated confidence (conformal prediction suggested)". Each set member maps to a candidate action.

## Options
1. Raw softmax top-k. No guarantee.
2. Split conformal, LAC score 1 − p̂_y (marginal guarantee under exchangeability).
3. APS / RAPS (adaptive sets). Larger sets; more code.

## Decision
Option 2, implemented in numpy (~20 lines, no MAPIE dependency). Calibration split by trial, inside the training geometries of each LOGO fold. α default 0.10.

## Consequences
Under a geometry shift the guarantee doesn't formally hold, so we report empirical coverage (S2) and never call it "guaranteed" on new geometries. Upgrade path: class-conditional (Mondrian) conformal if per-class coverage is uneven.
