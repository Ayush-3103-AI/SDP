# ADR-0002 — Learned, image-only cause model over joint causes; telemetry excluded

STATUS:      accepted
DATE:        2026-10-03
REVERSIBLE:  costly (one-way for evaluation validity)

## Context
The deck asks for explanations "expressed in process variables". The dataset's causes were induced by *commanding* setpoints, so commanded and measured setpoints reveal the label during trials.

## Options
1. Hand-written cause probabilities + telemetry evidence (Bayesian scoring). No training needed, but its accuracy can't be checked against the induced labels without circularity.
2. A learned classifier over joint causes (e.g. `flow_low`), fed the defect crop + defect class. Measurable against ground truth.
3. Option 2 plus telemetry inputs. Leaks the label.

## Decision
Option 2. Backbone: ResNet18 (ImageNet weights) on a 224 px crop, with the defect-class one-hot concatenated before a linear head. Telemetry is used **only** by deterministic sensor checks (FR-010), never as a model input.
**Fallback (if K1 or K2 fires):** Option 1, re-scoped as the explanation method, with its accuracy reported on the same LOGO folds.

## Consequences
Cheap at runtime (≈ 5 ms GPU). Cannot see thermal drift that's invisible in the image; sensor checks cover heater faults. Single-label: co-occurring causes are dropped from training (logged in T-0006).
