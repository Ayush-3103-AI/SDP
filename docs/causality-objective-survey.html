1 · The objective, decomposed

"A causality model that explains why a defect happened, what went wrong, and gives an array of plausible fixes for a human to choose from" breaks into six testable jobs:

  1. Why: name the cause (which process parameter, which direction).
  2. How sure: say how confident, honestly, including "I don't know".
  3. What went wrong: show the evidence on the image and in words.
  4. Array of fixes: a short ranked list of concrete, bounded actions.
  5. Safe choice: every option passes the safety gate; the human picks.
  6. Learn: the pick and its outcome improve the next ranking.

4 · A quick test we ran today

To check whether a symptom-first model is worth pursuing, the 9-way predictions from Krish's complete-data fine-tune were summed into three physical symptom groups chosen from extrusion physics before looking at results: none · under-extrusion (flow_low, speed_high, z_offset_high, nozzle_temp_low) · over-extrusion (flow_high, speed_low, z_offset_low, nozzle_temp_high).

9 causes3 symptom groups
Top-1 vs floor0.209 vs 0.254 (−4.5 pp)0.499 vs 0.475 (+2.4 pp; 4 of 5 folds above)
Balanced accuracy vs chance0.177 vs 0.1110.471 vs 0.333

This is exploratory, on test folds, with a model not trained for symptoms. It does not pass any gate. It does say the image carries a symptom signal that the 9-way split smears out; a model trained on symptoms is the cheapest next experiment.

5 · Recommendation

Take the pre-registered K2 fallback and upgrade it into a two-stage, symptom-first causality model. The image says what went wrong; a transparent Bayesian table says why and what to try; the existing gate and card let the human choose.
crop ──► Stage A: symptom model (image-only, ADR-0002 intact)
           none / under-extrusion / over-extrusion (+ severity), conformal set, Grad-CAM per symptom
     ──► Stage B: Bayesian cause ranking (ADR-0002 Option 1)
           P(cause | symptom) from the CC BY troubleshooting table + CAXTON physics
           × weak 9-way cause probabilities, flattened when the set is large
           + deterministic sensor flags (telemetry stays out of the model)
     ──► Stage C: top-3 fixes + "inspect manually"   (causes sharing a fix are merged)
     ──► existing gate L2→L1→L3→L4 ──► card ──► operator pick ──► verifier ──► success stats per fix
  • Why this one: it uses what passed (gate, card, verifier, latency); it is the fallback the project already committed to; it matches the only form prior art uses for defect → cause → remedy; and the symptom signal is above chance where the 9-way signal is not.
  • How it is measured: on the same frozen LOGO folds — symptom balanced accuracy vs floor (print bootstrap), and for the array: "true cause's fix ranked #1" and "in top-3" vs the floor ranking. ADR-0002 already says Option 1's accuracy is reported on those folds.
  • Contrarian view: per-print calibration (Margadji) — fine-tune on the first minutes of each new print — would likely lift the 9-way model the most, but it changes the evaluation protocol and assumes labelled frames per print. Keep it as the "with calibration" variant, reported separately.

7 · ADR stub

ADR-0010 — Symptom-first causality model with Bayesian cause ranking (K2 fallback)
STATUS:   PROPOSED (needs user + Dr. Meti approval; DESCEND on 06–09)
CONTEXT:  K2 fired on complete data (top-1 0.209 vs floor 0.254). Per-print appearance
          dominates image-only cause classification; Margadji 2024 reports the same gap.
          The ranked fix array, gate and HITL card are built and pass their tests.
OPTIONS:  (a) keep tuning the 9-way model (LP-FT, DINOv2, 4-head) — DG evidence says ≤ a few pts;
          (b) ADR-0002 Option 1 alone (hand-written priors);
          (c) symptom model + Option 1 Bayesian ranking (this);
          (d) per-print calibration; (e) telemetry fusion — rejected, leaks the label.
DECISION: (c), with (d) reported as a separate "with calibration" variant.
RATIONALE: symptom signal above chance (bal. acc 0.471 vs 0.333, exploratory); matches prior art's
          defect → cause → remedy form; reuses gate/card/verifier; pre-registered fallback.
CONSEQUENCES: CauseModel output contract changes (SCHEMA_VERSION bump); NFR-005 re-stated as
          symptom accuracy + fix-rank metrics; priors are hand-set and must be labelled as such.
REVISIT:  if the trained symptom model does not beat its floor with a print-bootstrap CI.
