## Steps
1. `uv run pytest tests/test_ui_data.py -q`
   Expected: `13 passed`   Time: < 1 min
2. Write the demo script (PowerShell, from the repo root; copy the whole block):
```powershell
@'
from dataclasses import replace
from pathlib import Path

import cv2
import numpy as np

from xqi.camera import open_source
from xqi.config import load
from xqi.explain.counterfactual import make_proposal
from xqi.orchestrator import Orchestrator, new_run_id
from xqi.printer import FakePrinter
from xqi.store import Store
from xqi.types import CauseEstimate, CauseSet, Detection

cfg = replace(load("config/default.yaml"), mode="advisory")
frames = Path("runs/_t0038_frames")
frames.mkdir(parents=True, exist_ok=True)
for i in range(600):
    img = np.full((480, 640, 3), 90, np.uint8)
    cv2.putText(img, f"T-0038 demo frame {i}", (20, 40), cv2.FONT_HERSHEY_SIMPLEX, 1, (255, 255, 255), 2)
    cv2.imwrite(str(frames / f"{i:04d}.png"), img)

class DemoExplainer:  # fixed two-cause set, so the card is PROPOSE with two proposals
    def explain(self, cd, frame, history):
        est = CauseEstimate({"flow_low": 0.64, "nozzle_temp_low": 0.22, "speed_high": 0.14}, "flow_low", 0.64)
        props = [make_proposal(c, est.probs[c], cd.severity, history[-1], cfg, cd.defect_id)
                 for c in ("flow_low", "nozzle_temp_low")]
        return est, CauseSet(("flow_low", "nozzle_temp_low"), 0.1, 0.7), (), [p for p in props if p]

def detector(frame):
    if frame.frame_id < 10:
        return []
    return [Detection(frame.frame_id, "under_extrusion", 0.85, (200.0, 150.0, 440.0, 330.0), 0.14)]

store = Store(Path(cfg.run_dir) / new_run_id() / "events.sqlite")
print("run:", store.path.parent)
Orchestrator(cfg, FakePrinter(), open_source(f"replay:{frames}@5", 0, 0), detector, DemoExplainer(), store).run()
'@ | Set-Content -Encoding utf8 runs\t0038_demo.py
```
   Expected: `runs\t0038_demo.py` exists (create `runs\` first with `mkdir runs` if it is missing)   Time: < 1 min

## If it fails
- No card appears: the demo in step 3 already finished or the card timed out (90 s). Re-run step 3, then refresh the browser.
- `Run not found` in the page: start step 3 before step 4, or pass `--run <run_id>` (the id step 3 printed).
- `--run latest` opens another run: pass `--run <run_id>` from step 3 instead.
- Apply does nothing and the events table shows `decision_blocked`: the gate re-check failed (reason in the alert). Comment the alert text on #38.
- Port 8501 busy: `uv run streamlit run xqi/ui.py --server.port 8502 -- --run latest`.
- `database is locked` in the page: the loop is mid-commit; refresh the browser.
