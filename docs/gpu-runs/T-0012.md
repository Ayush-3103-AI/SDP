# ⚠ GPU RUN — T-0012 Train the cause model on leave-parts-out fold 0 (early read on A3)  (issue #12)
Written against commit: the `T-0012: ready for GPU run` commit   ·   Est. time: ~35 min (25–60)   ·   Peak VRAM: ~1.5 GB (batch 32, AMP)   ·   Needs data: yes (crops)
Batch: sitting **G2**. Run it right after T-0065 Part 2 on the same laptop. If the success check below holds, carry
straight on with G3 (docs/gpu-runs/T-0013.md) in the same sitting; T-0015 and T-0017 (CPU, ~2 min) follow G3.
If the overfit check fails, stop after step 3 and send the output.

**What this does:** trains the image-only cause model (ResNet18) on fold 0 of the frozen leave-parts-out split twice:
rung 1 = the frozen-backbone probe (head only), rung 4 = the full fine-tune. It writes loss curves, checkpoints and
test predictions, and `reports/cause_fold0.md` puts both test top-1 values next to the majority floor.

## Prerequisites
- [ ] Setup A done on this laptop   - [ ] `git pull && uv sync` done
- [ ] T-0065 Part 2 done on this laptop: `data\crops.csv`, `data\crops\p*\*.jpg` (~90 k crops) and
      `data\splits\logo.json` (pulled from git; never re-run make_splits) exist
- [ ] Internet for the first run (torchvision downloads the ImageNet ResNet18 weights, 45 MB, once)
- [ ] `nvidia-smi` shows < 300 MB used; laptop plugged in; `powercfg /change standby-timeout-ac 0`

Run every command from the repo root.

## Steps
1. `uv run python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"`
   Expected: `True NVIDIA GeForce RTX 3050 ...`   Time: < 1 min
2. `uv run python scripts/eval_cause.py --floor`
   Expected: `# Cause floor (T-0010)` then `wrote reports\cause_floor.md`. The table names each fold's majority cause
   (probably `none`).   Time: < 1 min
3. GPU smoke run, then the Gate 3 overfit check:
   ```powershell
   uv run python scripts/train_cause.py --fold 0 --epochs 1 --limit 256 --out models/cause/smoke --report reports/smoke.md
   uv run python scripts/train_cause.py --overfit 20
   ```
   Expected: the first prints a JSON line, `fold0: train ... device cuda:0`, one `epoch 1: ...` line and
   `fold0: test top-1 ...` (the numbers mean nothing at 256 crops). The second prints
   `overfit: PASS (train loss 0.0xxx at step NN on 20 crops)`.   Time: ~2 min
   Then delete the smoke output: `Remove-Item -Recurse models/cause/smoke, reports/smoke.md`
   **If it prints `overfit: FAIL`, stop here** and send the whole output (see "If it fails").
4. Rung 1, the frozen-backbone probe:
   `uv run python scripts/train_cause.py --fold 0 --freeze-backbone`
   Expected: one `epoch N: train loss ... calib loss ...` line per epoch (≤ 15; it may print `early stop`), then
   `fold0: test top-1 ...` and `wrote reports\cause_fold0.md`. Files in `models\cause\probe\`: `fold0.pt`,
   `fold0.log`, `fold0.json`, `preds_fold0.npz`.   Time: ~10 min (≈ 30–40 s per epoch)
5. Rung 4, the full fine-tune:
   `uv run python scripts/train_cause.py --fold 0`
   Expected: as step 4, in `models\cause\finetune\`; `reports\cause_fold0.md` now has both rungs.
   Time: ~20 min (≈ 60–80 s per epoch)
6. Open `reports\cause_fold0.md`. Each rung has a line `Diagnosis (auto; edit after reading the curve): ...`. Read
   the curve under it and, if you see something the automatic line misses (e.g. calib loss rising from epoch 2,
   train loss flat), add one sentence after it.   Time: 5 min

## Success check

## If it fails
| Symptom | Fix |
|---|---|
| `overfit: FAIL` | Stop. Paste the whole step-3 output into issue #12. Don't run steps 4–5 (Gate 3: a model that can't memorise 20 crops has a pipeline bug). |
| `CUDA OOM: halving the batch to 16 ...` | Nothing to do: the script restarts the fold at half the batch. If it gets to batch 4 and still fails, close other GPU apps and re-run with `--batch 16`. |
| `RuntimeError: DataLoader worker ... exited unexpectedly` or "paging file is too small" | Re-run the same command with `--workers 2` (or `--workers 0`, ~2× slower). |
| `FileNotFoundError: data/crops/p...` | You are not in the repo root, or build_crops (T-0065 Part 2 step 2) did not finish: re-run it, it resumes. |
| `URLError` while downloading `resnet18-f37072fd.pth` | No internet. Download https://download.pytorch.org/models/resnet18-f37072fd.pth into `%USERPROFILE%\.cache\torch\hub\checkpoints\` and re-run. |
| An epoch takes > 3 min | Check `nvidia-smi` shows python on the GPU. If the GPU is idle, the disk is the bottleneck: copy `data\crops` to the SSD, or try `--workers 6`. |
| `torch.cuda.is_available()` is False | `uv sync --reinstall-package torch` (GPU_SETUP §C). |
