# ⚠ GPU RUN — T-0013 Run the full leave-parts-out cross-validation and the K2 kill check  (issue #13)
Written against commit: the `T-0013: ready for GPU run` commit   ·   Est. time: ~3 h (2–4 h; can run unattended)   ·   Peak VRAM: ~1.5 GB (batch 32, AMP)   ·   Needs data: yes (crops)
Batch: sitting **G3**, right after G2 (docs/gpu-runs/T-0012.md) on the same laptop once G2's success check holds.
After step 5, run T-0015 and T-0017 (docs/gpu-runs/T-0015.md, T-0017.md; CPU, ~2 min together) in the same sitting.

**What this does:** trains both rungs (probe, fine-tune) on all 5 leave-parts-out folds, evaluates them against the
majority floor, decides the **K2 kill check**, picks the rung, trains the runtime model `final.pt` and writes the
golden test crops that pin it.

- [ ] Setup A done on this laptop   - [ ] `git pull && uv sync` done
- [ ] G2 done on this laptop: step 3 of T-0012 printed `overfit: PASS`; `data\crops.csv`, `data\crops\`,
      `data\splits\logo.json` present

Run every command from the repo root.

## Steps
1. Both rungs on all folds (fold 0 is re-run too, with the same seed). Unattended:
   ```powershell
   uv run python scripts/train_cause.py --all --freeze-backbone; if ($?) { uv run python scripts/train_cause.py --all }
   ```
   Expected: for each of `fold0` … `fold4`, per-epoch lines then `foldK: test top-1 ...`; files `fold{0..4}.pt/.log/.json`
   and `preds_fold{0..4}.npz` in `models\cause\probe\` and `models\cause\finetune\`.
   Time: probe ~10 min per fold, fine-tune ~15–20 min per fold → ~2 h 15 min in all
2. Evaluate, apply the rung rule, decide K2:
   `uv run python scripts/eval_cause.py --model-dir models/cause/finetune --probe-dir models/cause/probe --copy-to models/cause`
   Expected output (4–5 lines):
   ```
   K2: PASS (top-1 = floor + x pp)          ← or K2: FAIL (...)
   wrote reports\cause_eval.md
   wrote reports/cause_errors.png (20 crops)
   copied the <rung> preds to models/cause
   rung: <rung>. Next: uv run python scripts/train_cause.py --final[ --freeze-backbone]
   ```
   Time: < 1 min
   - **Exit with `suspected leakage: ...`** (a fold above 0.98 top-1): stop, push what you have (send-back list without
     final.pt / golden), comment on #13.
   - **`K2: FAIL`**: that is the kill criterion. Stop here, push the send-back files you have, and tell Ayush. Do not
     run the final model.
3. Train the runtime model with the command step 2 printed (copy it exactly):
   `uv run python scripts/train_cause.py --final` (or `... --final --freeze-backbone` if step 2 chose `probe`)
   Expected: per-epoch lines, `final: ...`, then `wrote tests\fixtures\cause_golden (8 crops)`. Files:
   `models\cause\final.pt` (~45 MB), `final.log`, `final.json`, `preds_final.npz`, and
   `tests\fixtures\cause_golden\` (8 png + `expected.json`).   Time: ~20 min
4. Golden check: `uv run pytest tests/test_cause_artifact.py -q`
   Expected: `3 passed` (not `2 passed, 1 skipped`).   Time: < 1 min
5. Open `reports\cause_errors.png` (the 20 most confident wrong test crops). In `reports\cause_eval.md`, section Risks,
   replace `<fill in after looking: ...>` with one or two sentences on what you see (wrong labels at a parameter
   change? nozzle out of the crop? blur?). If one rung's diagnosis in `reports\cause_fold0.md` changed, note it too.
   Time: 5–10 min

## If it fails
| Symptom | Fix |
|---|---|
| `CUDA OOM: halving the batch to 16 ...` | Nothing to do; the fold restarts at half the batch and later folds keep it. |
| The laptop slept or the run was killed mid-way | Re-run only the missing folds, e.g. `uv run python scripts/train_cause.py --fold 3` (add `--freeze-backbone` for the probe). Each fold overwrites only its own files. |
| `DataLoader worker ... exited unexpectedly` / "paging file is too small" | Add `--workers 2` to the training command. |
| `no preds_fold*.npz in models/cause/probe` | Step 1's first command did not finish; check `models\cause\probe\fold*.log`. |
| Step 4: `ValueError: ... causes ... differ from config` | config/causes.yaml changed after training. `git pull`, check `git log config/causes.yaml`, tell Ayush; don't edit it. |
| Step 4 fails on `np.allclose` | Paste the output into #13; push final.pt anyway (Claude checks whether it is a CPU/GPU numerics difference). |
