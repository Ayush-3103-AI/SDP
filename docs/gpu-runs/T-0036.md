Written against commit: the `T-0036: ready for GPU run` commit (on top of the T-0062 commit)   ·   Est. time: 5–10 min   ·   Peak VRAM: ~0.3 GB (cause model ×2; + detector only if you set one)   ·   Needs data: optional (`data/crops.csv` + `data/crops/`; synthetic crops otherwise)

## Prerequisites
- [ ] Setup A done on this laptop   - [ ] `git pull && uv sync` done
- [ ] `nvidia-smi` shows < 300 MB used (close browsers, Discord; the VRAM number must be ours alone)
- [ ] Optional, better: `data/crops.csv` and `data/crops/` from T-0009 (`scripts/build_crops.py`). Without them the bench uses 500 synthetic 224 px crops; the timing is the same, the report names the source.
- [ ] Optional: `models/cause/final.pt` (T-0013/14) and `models/cause/qhat.json` (T-0015).
- [ ] `config/default.yaml` has `cause_model.device: "cuda:0"` (the default). Leave `detector.weights: null` unless the integrating team gave you a detector; with one set, the report adds a "with the detector resident" VRAM number and NFR-011 judges that one.

## Steps
1. `uv run python scripts/eval_latency.py --selftest`
   Expected: `selftest ok`   Time: < 1 min
2. `uv run python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"`
   Expected: `True NVIDIA GeForce RTX 3050 ...`   Time: < 1 min
3. `uv run python scripts/eval_latency.py --bench --crops data/crops.csv --out reports/latency.md`
   Expected: the report is printed, then `wrote reports/latency.md`   Time: 1–3 min
   (It loads the cause model on `cuda:0` plus the loop's EigenCAM copy, times 20 warm-up + 500 crops through
   crop + cause model + conformal + gate (p50/p95/p99), times EigenCAM on the same 500 crops separately, reads
   `torch.cuda.max_memory_allocated`, then loads and runs the detector only if `detector.weights` is set.)

## If it fails
- Note says `CPU smoke run` / heading says `on CPU` → torch is the CPU build or the device is `cpu`. See GPU_SETUP.md §C, `uv sync`, re-run step 3.
- `RuntimeError: Error(s) in loading state_dict` / `checkpoint ... use_defect` → `final.pt` was trained with another cause list or the old format. Move it aside (`mv models/cause/final.pt models/cause/final.pt.bak`) and re-run step 3; the report will say "random-init cause model".
- `KeyError: 'crop_path'` → `--crops` points at the wrong CSV; use `data/crops.csv` from build_crops, or drop `--crops` (`--crops none` = synthetic).
- NFR-001 FAIL by a few ms → re-run step 3 once with nothing else open. If it still fails, send the report anyway; it is a real result.
- `CUDA out of memory` → something else is on the GPU. Close it, check `nvidia-smi`, re-run.
- Detector errors (only with `detector.weights` set) → set it back to `null`, re-run, and paste the error on #36.
