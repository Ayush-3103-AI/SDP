## If it fails
- `SystemExit: --bench needs CUDA` → torch is the CPU build. See GPU_SETUP.md §C, then `uv sync`.
- `FileNotFoundError: models/yolo/best.pt` → T-0002 not delivered yet; stop.
- `ValueError: Unknown detector class` → same as T-0030: paste `YOLO('models/yolo/best.pt').names` on #36; don't edit code.
- `RuntimeError: Error(s) in loading state_dict` for the cause model → `final.pt` was trained with another cause list. Move it aside (`mv models/cause/final.pt models/cause/final.pt.bak`) and re-run step 3; the report will say "random-init cause model".
- NFR-001 FAIL by a few ms → re-run step 3 once with nothing else open (browser, Discord). If it still fails, send the report anyway; it is a real result.
- `CUDA out of memory` → something else is on the GPU. Close it, check `nvidia-smi`, re-run.
