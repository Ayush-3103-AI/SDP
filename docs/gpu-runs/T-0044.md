## If it fails
- `sqlite3.OperationalError: unable to open database file`: the pilot file is missing or the path is wrong; finish
  `docs/gpu-runs/T-0043.md` first, then pass `--db` exactly as written there.
- `no such table: choices`: the pilot was started but no card was answered; redo the T-0043 pilot.
- `n = 0 ... NO DATA` with exclusion "did not finish both blocks": the pilot stopped early (fewer than 12 cards
  or a missing questionnaire in a block). Delete `reports/study/pilot.sqlite` and redo the T-0043 pilot.
- Exclusion "median decision under 2 s": the participant clicked through; redo the pilot properly.
- Later (T-0045): point `--db` at the real study file (not the pilot file) and use `--out reports/operator_study.md`.
