## Prerequisites
- [ ] Setup A done on this laptop   - [ ] `git pull && uv sync` done
- [ ] T-0033 merged: `python -m xqi run` exists, and `python -m xqi ui --run R` dispatches to `xqi.ui.launch(R)`
- [ ] The orchestrator calls `xqi.ui_data.save_latest_frame(run_path, frame.image, dets)` at most every 0.5 s (this ticket's frame hook; check with `git grep save_latest_frame xqi/orchestrator.py`)
- [ ] `models/yolo/best.pt` present (from T-0002), and `camera.source` in `config/default.yaml` points at a replay folder of frames

## Steps
1. `uv run pytest tests/test_ui_data.py -q`
   Expected: `7 passed`   Time: < 1 min
2. `uv run python -m xqi run --config config/default.yaml --mode advisory --max-frames 300`
   Expected: exits 0 and `runs/<run_id>/events.sqlite` and `runs/<run_id>/frames/latest.jpg` exist   Time: 3–5 min
   Leave it running in one terminal if you want to see the view refresh live; otherwise let it finish.
3. In a second terminal: `uv run python -m xqi ui --run latest`
   Expected: Streamlit prints `Local URL: http://localhost:8501` and the browser opens   Time: < 1 min
   (Fallback if the `ui` subcommand is missing: `uv run streamlit run xqi/ui.py -- --run latest`)
4. In the browser check that all five elements are visible:
   - the latest frame with red boxes (if the replay had detections)
   - printer state (Printer, Nozzle, Bed, Flow / speed metrics)
   - mode (`advisory`)
   - a red alert banner, if the run raised any alert in the last 30 s of telemetry (otherwise none, which is correct)
   - the "Last 50 events" table, newest first
   While step 2 is still running, the frame and the table update about twice a second.
5. Take a full-window screenshot and save it as `reports/img/ui_live.png`.

## Success check
- `reports/img/ui_live.png` exists and shows the frame, the metrics column with Mode, and the events table.

## Send back (exact list)
git add reports/img/ui_live.png

## If it fails
- `Run not found` in the page: no `runs/*/events.sqlite` yet. Run step 2 first, or pass `--run <run_id>` explicitly.
- "Waiting for the first frame." forever: the orchestrator hook (prerequisite 3) is missing. Comment on #37; don't patch it here.
- `database is locked` in the page: the loop is mid-commit. Refresh the browser; the view is read-only and retries every 0.5 s.
- Port 8501 busy: add `--server.port 8502` after `xqi/ui.py` in the fallback command.
