# ⚠ GPU RUN — T-0037 Build the dashboard live view (read-only)  (issue #37)
Written against commit: T-0061 (parallel run 3)   ·   Est. time: 15 min   ·   Peak VRAM: none (CPU only)   ·   Needs data: no (synthetic frames)
Batch: run it in the same sitting as T-0038 (proposal card) and the T-0052 soak. No GPU, no detector, no model needed.

Since T-0061 the loop runs without a detector (`detector.weights: null`, the default) and without a cause model
(`build_explainer` logs one warning and the loop still runs). So this check needs only replay frames and the
fake printer. It runs on a team laptop because the dev laptop must not run the loop or a Streamlit server.

## Prerequisites
- [ ] Setup A done on this laptop   - [ ] `git pull && uv sync` done   - [ ] data present: none

## Steps
1. `uv run pytest tests/test_ui_data.py -q`
   Expected: all passed   Time: < 2 min
2. Make 300 synthetic replay frames (noise images, 1920×1056):
   `uv run python -c "import cv2, numpy as np, pathlib; d = pathlib.Path('runs/t0037_frames'); d.mkdir(parents=True, exist_ok=True); [cv2.imwrite(str(d / f'{i:04d}.png'), np.random.default_rng(i).integers(0, 255, (1056, 1920, 3), dtype=np.uint8)) for i in range(300)]"`
   Expected: `runs/t0037_frames/` holds 300 PNGs   Time: < 1 min
3. Copy `config/default.yaml` to `runs/t0037.yaml` and change two lines in the copy:
   - `printer:` → `kind: fake`
   - `camera:` → `source: "replay:runs/t0037_frames@2"` (2 frames per second, so the run lasts ~150 s)
   Leave `detector.weights: null`. Don't edit `config/default.yaml` itself.
4. `uv run python -m xqi run --config runs/t0037.yaml --mode advisory`
   Expected: one log line `no cause model (... missing): non-critical defects will ESCALATE` (none if you have a
   trained model), then it exits 0 after ~150 s. `runs/<run_id>/events.sqlite` and
   `runs/<run_id>/frames/latest.jpg` exist.   Time: ~3 min
   Keep it running in this terminal while you do steps 5–7.
5. In a second terminal: `uv run python -m xqi ui --run latest`
   Expected: Streamlit prints `Local URL: http://localhost:8501` and the browser opens   Time: < 1 min
   (Fallback: `uv run streamlit run xqi/ui.py -- --run latest`)
6. In the browser, check that all five elements are visible:
   - the latest frame (noise; no boxes, because there is no detector)
   - printer state (Printer, Nozzle, Bed, Flow / speed metrics)
   - mode (`advisory`)
   - a red alert banner only if the run raised an alert in the last 30 s of telemetry (normally none, which is correct)
   - the "Last 50 events" table (empty is correct here: no detector and no model means no events)
   While step 4 runs, the frame changes about twice a second.
7. Take a full-window screenshot and save it as `reports/img/ui_live.png`.

## Success check
- `reports/img/ui_live.png` exists and shows the frame, the metrics column with Mode = advisory, and the events table.

## If it fails
- `Run not found` in the page: no `runs/*/events.sqlite` yet. Start step 4 first, or pass `--run <run_id>` explicitly.
- "Waiting for the first frame." forever: `frames/latest.jpg` is not written. Comment on #37 with the step-4 log; don't patch it here.
- Step 4 fails with `ConnectionError` or `get_state failed`: `printer.kind` in the copy is still `octoprint`. Set it to `fake`.
- Step 4 fails with `replay folder not found`: run it from the repo root, or put the absolute folder path after `replay:`.
- `database is locked` in the page: the loop is mid-commit. Refresh the browser; the view is read-only and retries every 0.5 s.
- Port 8501 busy: add `--server.port 8502` after `xqi/ui.py` in the fallback command.
